# 画布交互与完整性升级

## 开源参考

- Fossify Paint: https://github.com/FossifyOrg/Paint ，GPL-3.0；参考其画布优先、常用绘画控件直接可达的组织方式，未复制其界面代码。
- Fossify 具体布局：https://github.com/FossifyOrg/Paint/blob/master/app/src/main/res/layout/activity_main.xml
- Drawpile 图层/工具面板：https://docs.drawpile.net/help/draw/clipping.html 、https://docs.drawpile.net/help/draw/brushsettings.html ；参考选择、显示、锁定与参数分别呈现的模式，不引入第二套文档或撤销系统。
- 既有 AndroidSVG、Drawpile/Drawdance、AndroidX ExifInterface 接入保持不变。

## 行为

常用画笔、框选、橡皮、笔刷与图层固定可见；第二排提供撤销、重做、添加、居中和更多。短横屏收起第二排，操作仍可经更多/菜单访问。AI 发送与停止共用按钮，范围、提示词及自动识别继续按需展开。工作区列表长标题最多两行；对话页压缩输入区、统一发送/停止并适配键盘，后台新增工作区在任务结束后刷新。原配色和登录/订阅交互不变。

修复：自由画笔保留填色状态、橡皮工具状态不一致、过期图层/对象对话框、无效数值导致关闭编辑器、锁定层可从UI删除、越界变换被截断造成几何变形、暂停后的残留触摸状态。

保存队列保留失败及后续版本，按原顺序重试。队列未排空时拒绝翻页/退出；失败显示重试按钮。共享写入屏障阻止 MCP 在前台或后台对有未保存本地版本的同页编辑。不同页面互不阻塞。旋转/配置变化通过非配置状态保留保存队列、最后待保存页及重试状态；新界面重新绑定观察者，旧 Activity 不被队列持有。系统强制终止、存储介质损坏等仍不能由界面承诺数据绝对不丢；本批不声称“零漏洞”。

SVG 在原有大小/外部资源限制之外检查 XML 结构、最大64层嵌套、1000元素、命名空间和事件属性，避免畸形或过深内容直接进入渲染。

## 检查

JVM：保存失败/恢复顺序、页面隔离、锁定层保护、越界原子拒绝、过期图层设置、无效字号保留输入、单按钮发送停止、画笔恢复、SVG畸形输入。

Android：未保存页拒绝离线MCP写入，320×568、640×360、800×600dp布局边界/触控尺寸/画布空间和截图，以及既有MCP、像素渲染、手势、订阅持久化检查。

本批先在升级分支完成验证；APK和中继保持同一提交，之后统一部署。
