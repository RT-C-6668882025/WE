# WE v0.4.7 Preview

- Android NDK/JNI port of Drawpile classic brush mask kernel, pinned to upstream 2c2a616f. New drawing strokes use pressure-sensitive dabs. This is a partial engine port; full Drawdance canvas, layers, MyPaint and collaboration are not included.
- Shared editor/snapshot/MCP stroke renderer and persisted engine identifiers; old vector strokes retain their renderer.
- Four clear tools with selected checkmark: brush, move, rectangle selection and whole-stroke eraser. Separate undo/zoom row and in-app button guide.
- Subscription login unchanged.
- Release requires unit tests, lint, Android instrumentation including native brush pressure/replay, and persistent login storage checks.

Preview signing follows the existing CI debug signing setup. Preserve existing app data if installation reports an incompatible signature.
