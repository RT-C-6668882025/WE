# WE v0.5.0 Preview

- Handwriting and drawing now open the same current workspace canvas and latest page; switching input modes preserves page identity and ink. Workspace history opens that canvas too.
- Compact toolbar: brush/selection/eraser/undo/brush panel/centre. Pinch replaces zoom buttons; import, single-finger pan, content editing, canvas settings and help move into Menu. Page navigation only appears for multipage PDFs.
- One Send action with explicit Whole page / Selection / Text only scope, editable instruction presets, optional Auto recognition (off by default), conditional Stop and generated-page entry.
- Editable system prompt and per-workspace page-task template. Recognition/correction records live in the workspace.
- Drawpile integration now builds pinned upstream Drawdance C/C++ core, bundled MyPaint, protocol messages, Zstandard and tile canvas without Qt. Drawing uses the actual classic brush engine -> dab protocol -> native 15-bit tiled canvas -> flattening pipeline over JNI. Completed stroke rasters are cached; old vector/classic strokes keep their original renderer.
- This is a native core integration, not the complete Drawpile application: layer UI, collaboration, and MyPaint brush selection are not exposed. Real tablet latency still needs measurement.
- Imported PDF ownership, per-workspace page restoration and original source/ink preservation retained. Subscription login unchanged.

Preview signing follows existing CI setup. Preserve existing data if Android reports an incompatible signature.
