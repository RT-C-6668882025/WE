# WE v0.4.3 Preview

- 首页继续作为手写入口，增加打字和系统语音输入。设备没有语音识别服务时明确提示。
- 原“历史”改为“工作区”，统一展示旧会话及已有学习工作区；选择后在首页继续同一任务，恢复最近对话上下文，不再另开会话。
- 每个工作区的“资料”内可查看文件、导入 PDF、打开最近学习页或重命名。
- 设置中移除独立“PDF 练习工作区”和“WE 工作区 · Skill / MCP”入口，保留配置。
- 关于页面保留，介绍改为 WE / Write Everything 和 RT 的项目信息，保留 GPL、Moling 上游及第三方致谢。
- 旧会话文件保留，工作区建立索引和参考文本；已有 Agent 资料、笔迹及登录不改动。
- 修复 Android 应用目录别名被事件日志框架误判为符号链接，导致第二轮学习失败的问题；保留日志目录及子路径的安全检查。

本版调整导航及任务续接，不宣称已实现 WordTok 式对外 MCP 服务；当前内置 MCP 客户端不等于对外控制接口。

验证：新增应用目录别名下连续学习的回归测试；发布流程要求单元测试、Lint、APK 构建和 Android 设备集成测试全部通过。登录代码沿用 v0.4.2。GitHub Actions 使用 CI 的构建签名，可能无法直接覆盖本对话交付的本地签名 APK；请保留原应用及数据。系统语音服务和实际平板操作仍需设备验证。
