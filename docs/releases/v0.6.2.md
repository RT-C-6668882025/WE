# WE v0.6.2 Preview

- One-click public MCP setup: Settings → Agent connection · MCP → Copy MCP address.
- Default WE relay: https://we.wordrelay.dpdns.org. First use validates protocol 2, pairs, encrypts and stores identity, starts the device service and copies one full MCP URL.
- Existing pairings and URLs are reused, including custom relay pairings. Concurrent setup is serialized to avoid duplicate pairing identities.
- Reopening the app restores a previously enabled connection; transient failures reconnect. Stop remains available in settings and the notification.
- Local configuration and explicit unpairing move into Advanced settings. Failed remote revocation preserves the original identity for retry.
- Pairing credentials are copied as sensitive clipboard content and are not rendered in the UI or logs.

The service still depends on Android background permissions, network and relay availability. An authoritative 401 is shown as revoked instead of silently creating a different URL.
