# WE v0.4.2 Preview

修复并补充浏览器跳回本机地址时的授权恢复。

- 已校验的回调不会因浏览器断开、无法读取确认文字而丢失。
- 单个本机连接中断不再结束等待；取消和授权总超时仍有效。
- 授权进行中新增“浏览器回调失败：恢复本次授权”。浏览器最后停在本次 127.0.0.1 错误页时，可复制完整地址到 App 内恢复；不必通过浏览器再次访问本机地址。
- 仅接受当前监听端口的 HTTP 回调地址，并继续校验 state、client_id 和原 PKCE 流程。地址不记录日志、不持久化，请不要分享给别人。

此修复针对截图中的 ERR_NETWORK_CHANGED 回调连接故障及代码中相关的中断处理缺口；不表示已在用户设备复现全部原因。

保留 v0.4.1 的工作区和自动学习功能。同一环境签名，可覆盖本对话交付的 v0.4.1 安装包。未重新签发 OAuth 客户端或改变授权范围。

验证：97 项协议/本机回调检查，94 项单元测试、Lint 和 APK 构建；真实账号授权仍需设备验证。GitHub Actions 仍暂停，直接提供本地构建 APK。
