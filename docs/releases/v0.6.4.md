# WE v0.6.4 Preview

对照 WordTok 的原生后台连接实现，统一为 HttpURLConnection；设备连接超时 5 秒、读取超时 10 秒，空闲轮询间隔 4 秒，失败按 1/2/4/8/15 秒退避。配对仍是 health → 空 POST pair → 保存固定地址；首次请求 15 秒超时，保留 WE 服务身份校验和设备加密存储。

新增后台唤醒锁、电池优化豁免入口、手动重新连接、通知栏真实状态；后台结果发送失败先补发原回执，再领取新指令。划掉任务停止服务，配对地址保留，重新打开按用户设置恢复。系统重投使用 START_REDELIVER_INTENT。

用户仍只需点击复制 MCP 地址。保留现有配对，不修改服务器、WordTok 和其他站点。Android 公网配对和 MCP initialize 测试必须通过才发布 APK。

技术边界：WordTok 首次配对使用 WebView fetch；WE 保留原生界面，采用相同 HTTP 请求顺序和空 POST 配对。此次对齐后台网络、重试及保活行为，不声称两个应用的 UI 或运行时完全相同。
