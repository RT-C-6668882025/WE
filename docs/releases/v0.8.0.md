# WE v0.8.0 Preview

- 修复 MCP 新建工作区后已打开列表不刷新的问题，保留搜索、筛选与管理状态。
- MCP 创建/编辑页面后发送结果通知；保存待打开页面，App 恢复前台后仍能发现后台结果，当前笔迹不会被自动替换。
- 所有工具下均可双指平移缩放；仅笔输入时单指可移动画面；移动工具可从页外拖动。手势过程中拒绝外部覆盖。
- MCP 增加实心矩形/椭圆/多边形、三次贝塞尔曲线、指定位置灌色、区域或整层变换/删除、笔迹重着色与部分笔刷样式修改。
- get_canvas_context 返回分页对象索引、边界和样式，以及真实支持的操作、混合模式和笔刷预设。
- 设备端与中继需同时升级。工具数量仍为 16，新增操作通过 edit_canvas 暴露；只安装 APK 不会更新旧中继的工具 schema。

画布仍为有限页面。矩形范围选择整条笔迹；尚不包含像素蒙版、剪贴蒙版、图层组、文字/图片对象、滤镜或 PSD 互通。完整能力说明见 docs/drawing-capabilities.md。

既有订阅登录与模型交互逻辑未修改。本发布不代表目标服务器已部署新中继。
