# WE v0.4.8 Preview

- Two-finger pinch zoom anchors at the fingers; two-finger pan works in every tool and pen-only mode. Lifting fingers cannot leave an accidental stroke.
- Selected tools have a contrasting background. Eraser shows a visible blue radius immediately, follows touch and pen hover, and reports erased stroke count.
- An eraser drag is one undo step. Switching to a navigation gesture or cancellation restores the pending erase; PDF/generated backgrounds stay intact.
- Reset-view button restores the centred full page. Updated in-app gesture and tool guide.
- Android regression tests cover pinch focal coordinates, pen-only navigation, no gesture ink, visible cursor excluded from AI snapshots, eraser cancellation and undo.
- Subscription login unchanged. Preview uses the existing CI signing setup; preserve existing data if installation reports an incompatible signature.
