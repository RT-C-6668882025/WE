# WE v0.11 Preview — canvas-first editor

Uses Drawpile's mobile Tool/Brush dock organization as the single interaction reference (https://docs.drawpile.net/help/draw/brushsettings.html). WE retains its Android editor, document model, native Drawdance rendering, and MCP contracts; this is not an import of the Qt application or a claim of feature parity.

- Phone: one 48dp core tool strip. Wide windows: a 64dp scrollable tool dock. Undo/redo stay in the top bar; empty history disables them using persisted history, including after reopen and external edits.
- Single-page documents hide the redundant page/preset row. AI options move to a scrollable modal. Idle saving no longer occupies a second status row; failures and retry remain explicit. Full status text remains accessible in the menu.
- Current shape and eraser type appear on the tool buttons. Selection, keyboard focus and press ripple share one style. Long-press shortcuts supplement the visible menu.
- Menu groups tools, adding objects, view/presets, file/input settings and AI/workspace. Tool menu no longer duplicates undo/redo.
- Auxiliary text uses stronger contrast. Brush swatches use two rows of three, sliders/spinners have 48dp targets and names. AI request text and send scope survive activity recreation.
- Layout verification now checks target height as well as width, at least 60% canvas height for idle single-page layouts, and a reduced-height keyboard-sized window. These are measured layout tests; they do not replace physical-device IME, TalkBack or ARM performance testing.

Existing subscription login/model selection and MCP schema are unchanged. Layer groups, cross-layer masks, filters and PSD are still outside this release.
