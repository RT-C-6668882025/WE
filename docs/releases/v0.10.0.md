# WE v0.10.0 Preview — canvas interaction and save recovery

Includes the staged 0.9 artwork integration. This batch remains on the upgrade branch for coordinated device/relay deployment.

- Fixed, equally sized core tools replace the horizontally hidden toolbar. Secondary actions collapse on short landscape windows; the canvas retains working space. Existing colors and subscription flows remain.
- AI send/stop is one action; active tools and eraser choices use the same selected-state path. The brush button always returns to freehand.
- Layers expose selection, visibility and lock state; stale layer/object/selection dialogs reject changes instead of targeting a newly active object. Invalid input stays in its editor.
- Local layer and transform actions use the MCP edit validator. Locked layers cannot be deleted; out-of-page transforms fail atomically instead of distorting objects.
- Failed saves stay in an ordered retry queue. The UI exposes save status/retry and blocks page departure until saved. A shared write guard prevents offline MCP changes while local revisions remain unsaved.
- Configuration changes retain failed/pending save revisions and retry state, restoring the unsaved page in the new editor.
- Pausing cancels transient touch state so the next session is not stuck busy.
- Self-contained SVG validation checks XML structure, nesting, namespaces and event attributes before persistence/rendering; parsed validation is bounded and cached.

Validation includes failure/retry ordering, offline MCP exclusion, stale dialogs, invalid text settings, tool restoration, and native phone/landscape/tablet layout captures in addition to existing artwork, drawing and subscription regression.

No claim of zero defects or full Photoshop parity. Native layer groups/cross-layer masks, PSD and filters remain outside this batch.
