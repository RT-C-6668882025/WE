# WE v0.6.5 Preview

删除旧版原生配对、保持连接开关、本机配置入口和依赖本机 HTTP 端口的后台启动流程。

以 WordTok 为连接基准：首次配对直接在 Android WebView 里运行相同的 health → 空 POST pair 的 fetch 代码（每次 15 秒超时，沿用浏览器默认重定向行为），解除配对也走相同 fetch /device/close。页面采用 WordTok 的连接卡样式、配对／复制固定地址／重连／解除配对和后台权限入口。

后台保持 WordTok 的 HttpURLConnection 请求、鉴权、轮询、回执补发、指数重连、唤醒锁、服务重投、划掉任务停止和打开应用自动连接行为。现有 WE 加密配对文件由宿主适配器读写，身份和工作区数据保留。仅产品名称、域名和执行的工作区工具不同。

WE 中继默认精确允许 https://localhost，与 WordTok 的 Capacitor HTTPS 来源一致；旧部署若显式配置了 origins=[]，需更新 WE 中继启动文件。此次代码更新不操作服务器，不改变数据目录，不修改其他服务。

验证包括 Node 浏览器请求契约、真实 Android WebView HTTPS fixture（含 CORS、空 POST、保存、固定地址、解除配对）、原生服务生命周期及独立公网配对／MCP initialize／设备轮询。公网链路未通过时不自动发布 APK。
