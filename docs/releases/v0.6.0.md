# WE v0.6.0 Preview

- Restore handwriting directly on Home, explicit Send and in-place typed input.
- Workspace selection resumes the conversation on Home. Drawing remains a separate editor in the same task.
- Keep software Home handwriting drafts per task and archive submitted raw ink. Drafts adapt to viewport size when restored.
- Continue/new drawing actions maintain a separate drawing identity; AI learning-page generation no longer replaces the active drawing.
- Persistent upstream Drawdance layer canvases support cross-stroke smudge, Classic/MyPaint parameter presets and local erasing.
- Layer visibility, locks, opacity, blend modes, ordering, duplication and deletion; undo/redo; shapes, contiguous fill, eyedropper and PNG export.
- Reuse MIT-licensed xnotes affine geometry for selection rotation, mirror, scale, movement and copy/delete.
- Editor, snapshots and MCP share the same layer renderer and saved brush/layer metadata.

This is an Android editor using the Drawdance core, not the complete Qt Drawpile application. It does not provide desktop brush-pack import, animation or collaboration. Jetpack Ink remains under adapter evaluation. Physical pen latency and Huawei proprietary-layer draft replay have not been verified. Drawing working resolution is capped at 1536 pixels on the longest side, and PNG exports at 2048.

This locally built preview may have a different debug signing key from previous downloads. Keep the existing installation and data if Android reports a signature mismatch.
