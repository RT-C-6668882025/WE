WE（Write Everything）Android 预览版。

- 在 Android 内运行 Skills、MCP 和文件工具，复用已有 ChatGPT 订阅；无需电脑或 Termux。
- 支持多个本地工作区、导入 Skill 文件夹及公开 HTTPS MCP。
- 生成的文本可转为分页学习纸，提供留白/紧凑两种排版；也可新建空白纸书写、绘画。
- PDF/学习纸支持笔迹自动保存、矩形选区、整页/选区识别、批改解释、可选停笔识别和仅笔书写。
- 识别结果可带回原工作区，由用户确认后继续生成下一份学习材料。
- 保留订阅登录加密保存与进程重启恢复。

发布门槛：同一源码的单测、lint、debug/release 构建、API30 模拟器 Skill→MCP→文件合同、学习页分页与笔迹恢复，以及 Keystore 强停恢复检查通过。

当前边界：真实订阅账号的工具调用及平板手感仍需实机验证；不支持 MCP OAuth/stdio、任意 Python/Node 脚本 Skill、自适应图形框架、富文本交互组件。当前排版为文本学习纸，反馈需手动带回并确认执行。

安装包沿用持久登录测试包名，使用 CI debug 签名。不同构建签名可能无法覆盖安装；请保留旧安装和资料，勿为安装新版直接卸载。此版不标记生产稳定版。
