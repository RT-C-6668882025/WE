# WE v0.4.5 Preview

- 工作区增加名称搜索、置顶优先和最近/名称/最早使用排序。
- 增加“进行中 / 已归档 / 回收站”分类；支持单个或批量置顶、归档、取消归档、移入回收站与恢复。
- 移入回收站保留会话、资料、学习页、Skill 和笔迹；旧会话迁移不会重新创建已移除的任务。恢复继续沿用原工作区 ID。当前任务移入回收站后，首页切到新任务。
- 新建空任务在首次输入后自动使用首问命名；用户手动重命名后不再自动改名。
- MCP 增加 manage_workspace，允许外部 Agent 置顶及归档；list_workspaces 可按名称和归档状态筛选。回收站操作保留在应用内。
- 登录模块沿用用户确认可用的 v0.4.4，本版不改动授权、网络或凭据代码。

验证：新增数据保留、恢复、旧记录防重建、搜索与排序、自动命名及实际工作区界面的回归；发布流程仍要求单测、Lint、构建和 Android MCP/学习链路集成测试通过。公网 MCP 中继尚未部署。

GitHub Actions 的 APK 使用该运行环境的构建签名；覆盖升级前需确认与已安装版本相同。不要卸载含有资料的旧应用来切换签名。
