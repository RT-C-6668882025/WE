# WE v0.7.0 Preview

- 工作区统一进入画布，手写和绘画改为同一页面上的笔刷预设。顶部管理工作区和页面；工具栏负责写画；底部 AI 输入和发送，范围/指令/自动识别按需展开。
- “页面”集中管理空白页、PDF 导入和页面切换。保留原有视觉配色与笔迹，继续最近使用的页面。
- MCP 新增 list_canvases、create_canvas、get_canvas_context、edit_canvas、canvas_history、export_canvas，共十六个工具。支持原子绘制笔画/形状/填色/橡皮，图层管理与笔画变换，持久化撤销重做，透明 PNG 导出和 MCP 图片预览。
- 外部编辑携带 expected_revision，当前落笔、未完成保存或版本冲突时拒绝覆盖。前台当前页直接同步；关闭页使用同一份保存数据。
- 模型配置前移，画布与对话中提供“AI 模型设置”。继续打开原有 ChatGPT 登录与模型选择页；既有授权、模型目录、选择与登录持久化逻辑未修改。
- 公网配对地址与已有配对身份保持不变。服务端必须同步部署本版本工具定义；仅升级 APK 不会让旧中继出现新增工具。服务器本地升级方式见 docs/drawing-mcp-deployment.md。

原始 PDF 保持不变；所有坐标为 PDF 页点。画布仍为有限页面，不包含无限画布或逐笔实时订阅。现有订阅模型调用仍使用原有账户与额度。
