# WE v0.4.6 Preview

- MCP 生成页支持结构化 page：标题、正文、题目、答题留白、书写区、绘图区及矢量参考图。生成的 PDF 内容与手写笔迹位于同一页面。
- 平板笔排版默认正文 20 点、行高 32 点；题目与答题空间优先同页，支持横/竖版及左右手批注边距。普通文本输入仍兼容。
- read_page 同时返回页面图像、笔迹及内容块坐标，包含题目与答题区的关联，供外部 Agent 理解“写在什么内容上”，再发布新版继续学习。
- 首页入口改为手写、绘画、打字；独立语音入口移除，语音可使用输入法。
- 绘画页默认不触发停笔 AI，增加笔迹颜色、粗细、擦除和撤销。擦除只影响笔迹，原生成内容保留。旧黑色笔迹兼容。
- 绘画交互参考 Drawpile；本版未移植其 Qt 绘画引擎、图层或多人协作能力。公网 MCP 中继仍需部署。

验证：排版分页、文本完整性、题目/答题区关联、输入约束、旧笔迹兼容及笔色/擦除/撤销回归；Android 测试包含实际 PDF 上落笔、图像像素、擦除恢复，以及 MCP 结构化页面闭环。发布流程要求全部检查通过。

本版不修改订阅登录模块。CI 构建签名可能与此前本地包不同，请勿卸载旧版来切换签名。
