# WE v0.4.1 Preview

写下需求，Agent 完成后直接打开可书写的学习页；继续写、画或圈选，识别反馈自动进入下一轮。

- 工作区需求自动生成并打开学习纸，不再手动找文件、排版、跳回执行页面。
- 手写反馈携带原材料、页码、笔迹版本和选区，Agent 据此批改、解释、生成修改版或下一课。
- 停笔后自动继续；等待期间继续书写时，生成结果先保留，避免抢切页面。
- 原 PDF 和笔迹独立保存；完成的学习页可以重新打开。中断任务不会自动重放 MCP 操作。
- 收起 Skill/MCP 设置和细分工具，保留需求与纸面为主的入口。
- 修复上游读取工具对合法 JSON 转义路径的兼容问题，保证跨轮读取原学习材料。

全部编排在 Android 内完成，继续使用已有 ChatGPT 订阅接入。本版仍为文本学习纸，未集成 DSH Go、RikkaHub、Excalidraw 或 Jetpack Ink，也不支持任意 Python/Node Skill 脚本。

本次发布由同一源码的单元测试、Lint、APK 构建和 Android 模拟器仪器测试通过后上传 APK。模拟模型验证工具与页面流程，真实订阅识图质量和手写笔体验仍需实机反馈。
