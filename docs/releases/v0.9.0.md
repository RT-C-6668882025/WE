# WE v0.9.0 Preview — editable artwork objects

- Integrates AndroidSVG 1.4 (Apache-2.0) into the existing canvas renderer for SVG paths, gradients, groups, clipping and text.
- Adds persistent SVG, text and PNG/JPEG objects; supports the existing layer, transform, duplicate, erase, undo/redo and export flow.
- Adds app tools for text, image import, vector source insertion and editing existing text/vector content.
- AndroidX ExifInterface normalizes phone photo orientation before bounded PNG import.
- MCP edit_canvas supports svg/text/image/replace_artwork. get_canvas_context supports paginated source reads for large objects.
- Relay health exposes tools_schema_sha256; server deployment verifies the exact schema, not only the count of 16 tools.

SVG is editable as one source object; its internal groups/clip paths are not native WE layers. Native layer groups, cross-layer masks, PSD and filters are not included. Images are bounded and may be downsampled; SVG external resources, scripts and animation are not supported.

This batch is prepared together with its relay schema. Do not deploy the older relay with this APK. Existing subscription interaction remains unchanged.
