# WE v0.6.6 Preview

WE 独立公网入口改为 https://we.wordrelay.dpdns.org:8444，客户端默认地址、健康检查与文档同步更新。保留 WordTok 的 WebView 配对／撤销与原生后台连接流程，不需要用户手填服务器地址。

已有官方 WE 443 配对首次读取时原子迁移到 8444，agentToken、deviceToken 和其他字段保留，不向中继重新申请身份。自定义中继和其他端口不迁移。外部 Agent 需重新复制并更新完整 MCP 地址，原来的 443 地址仍可能不可达。

服务器侧保持 we-mcp.service、127.0.0.1:8787 与 /var/lib/we-mcp/relay.json，8444 的 nginx/TLS 入口由服务器终端侧配置。不要修改 WordTok、Hermes 或公众号服务。线上中继须允许应用的 https://localhost 来源，以支持 WebView fetch。

验证包含端口迁移、凭据保留、幂等迁移、自定义中继保留、本地 WebView HTTPS 与 8444 公网配对、MCP initialize、设备轮询；公网验证通过后才发布。
