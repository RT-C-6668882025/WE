# WE v0.4.4 Preview

- 新增对外 MCP：设置 → Agent 连接 · MCP。本机端点运行在 Android 前台服务，支持查看工作区、资料、Skill、PDF 和已保存手写图像，写入资料和发布新版学习页。
- 新增 WordTok 式配对中继源码：部署独立 HTTPS 中继后，Android 主动连接并执行工具，外部 Agent 使用固定配对地址。没有附带已托管公网域名，不能填写 WordTok 原有地址。部署见 mcp/README.md。
- 写入带持久回执和 operation_id；重试不重复创建，旧文件需 SHA-256 版本匹配，原学习页及笔迹不覆盖。中途进程被杀时报告不确定状态，不自动重放。
- MCP 配对使用独立 Android Keystore 加密，不读取或共享 ChatGPT 订阅令牌；可停止服务或撤销配对。仅绑定 loopback，公网由 HTTPS 中继转发。
- 登录页显示当前阶段、当前阶段耗时和总耗时，保留各阶段耗时；等待浏览器回调时提示保留原授权页面。已有登录避免误触重复授权。未宣称加速 OpenAI 浏览器授权服务。

验证：发布流程包含单测、Lint、APK 构建、MCP 中继真实 HTTP 回归、Android 上的 HTTP 工具调用/真实 PDF+手写图像/两轮学习/前台服务及加密配对测试。公网真实域名、手机后台保活和真实账号授权速度需部署及设备实测。

GitHub Actions APK 使用 CI 签名；本对话交付的同签名 APK 可覆盖此前本地构建版。不要为切换签名卸载有数据的应用。
