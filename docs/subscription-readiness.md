# 订阅模型功能与验收（v0.3.0）

## 本轮范围

集中订阅模型，不扩展 PDF、Drive、Room、Agent。

- 模型列表来自已登录账号公开 `/v1/models`，按 `visibility=list` 读取 `slug` 和 `display_name`、去重，不伪造或硬编码模型。列表不提供统一图片能力保证，界面按实测标记。
- 文字模型与图片/手写/PDF模型独立选择；图片可显式沿用文字。保存时校验最新目录成员，目录移除的 ID 不自动替换成另一个模型。目录缓存仅内存、同会话共享；重登和退出清除。
- 主界面文字、无本机识别时的图片转写、PDF视觉任务，统一从 SubscriptionSelection 读取配置。直接视觉模式为显式开关，否则本地优先。识别后沿用低笔画闸、空输入、/new、历史与回答，不静默跨计费接口。
- 设置可测试所选文字模型与图片转写模型，展示响应及按ID区分的本次会话测试状态。测试不自动保存选择，不将未测模型标记已支持图片；测试会消耗订阅额度。
- 授权、模型目录、请求错误与最终是否启用分开显示。授权应用持有，页面切换不取消。列表/请求统一在令牌临期时检查刷新，轮换失败需重新登录，不重放旧授权码/刷新令牌。退出清理会话、目录和测试状态，保存的模型偏好可保留但未登录不能调用。
- 错误在设置、书写、PDF使用一致的安全错误码/HTTP状态及指引，不输出任意上游响应或令牌。PDF批改使用学习提示，避免原文言人设的30~80字限制影响详细批改。

## 测试边界

原 v0.1.4 已由用户实机确认授权、模型目录、文本、图片四项通过。v0.3.0新增：模型目录过滤与去重、跨文字/视觉模型实际请求体契约、显式视觉模式跳过本地等待、目录移除禁止替换、PDF学习提示、真实生产设置Activity的模型保存与销毁重建（Robolectric/API34）。UI测试通过反射装入合成目录和授权布尔状态，不使用真实用户凭据、不进行OAuth或推理，不宣称替代实机完整验收。

仍需实机验证：本账号当前每个候选模型的实际图片能力、主界面笔迹识别准确度、所有设备的浏览器返回/进程回收、大PDF与电子墨水触控。

## 明确限制

凭据仍只在内存，完整进程退出后需重新登录；暂不引入未经验证的加密存储/恢复流程。当前单账号注册，多账号管理和持久化会话未完成。测试构建采用独立包名，旧数据不被覆盖；正式升级签名链尚未配置。未优化网络速度，不宣称所有账号都具备相同模型或额度。
