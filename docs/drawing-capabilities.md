# 绘画能力与验收范围

目标：AI 与人编辑同一份可继续修改的画布；MCP 暴露实际编辑能力，而不是仅返回一张图片。

参考官方移动端文档：
- Sketchbook 手势：https://help.sketchbook.com/docs/gestures
- Sketchbook 变换：https://help.sketchbook.com/docs/transforms
- Sketchbook 工具：https://help.sketchbook.com/docs/tools-in-sketchbook
- ibisPaint 图层：https://ibispaint.com/lecture/index.jsp?no=156

## 本次实现

| 能力 | MCP / App 行为 |
| --- | --- |
| 外部新建工作区 | 已打开列表原位刷新，保留搜索和筛选；对话页在前台刷新 |
| 后台绘画结果 | 创建和成功编辑都通知 App，并保存待打开页面；暂停期间的结果恢复后仍可发现 |
| 导航 | 任意工具下双指平移缩放；仅笔输入模式下单指平移；移动模式可从纸面外拖动 |
| 忙碌保护 | 导航手势中也拒绝外部覆盖，避免 AI 操作打断当前操作 |
| 对象检查 | get_canvas_context 返回每批 100 个对象索引、图层、边界、颜色、粗细、笔刷和下一偏移量 |
| 能力发现 | 同接口返回实际支持的动作、混合模式、笔刷预设和图层上限 |
| 几何绘制 | 线、矩形、椭圆、多边形、三次贝塞尔曲线；封闭形状可填实色 |
| 填色 | 指定 x/y 种子，仅对目标层灌色；省略时兼容旧的 (0,0) 行为 |
| 局部编辑 | transform/delete_strokes/restyle 可按对象索引、矩形范围或整层操作 |
| 样式调整 | restyle 修改颜色、粗细或部分笔刷属性，保留其他属性 |
| 图层 | 添加、重命名、可见性、锁定、不透明度、6 种混合模式、排序、复制、删除 |
| 历史 | 批处理原子提交、版本冲突检查、持久撤销重做 |
| 输出 | 背景或透明 PNG、图片预览，与 App 使用同一渲染器 |

## 还不能称为 Photoshop 完整能力

当前图层仍最多 32 层，画布是有限 PDF 页面；矩形范围选中的是有采样点落在范围内的整条笔迹，不是逐像素选区。

还未实现：图层组、像素蒙版、剪贴蒙版、调整图层、魔棒/套索像素选区、羽化、文字对象、图片素材对象、渐变、滤镜、透视/网格变形、PSD 导入导出、无限画布。这些需要扩展文档模型、渲染和 UI，并逐项提供同等的 MCP 接口，不能仅增加工具名称。

建议后续按顺序实施：图片/文字对象 → 图层组与蒙版 → 选区布尔运算及羽化 → 渐变/调整/滤镜 → 透视与格式互通。

## 验收

- JVM：编辑原子性、封闭形状/曲线序列化、区域重着色、整层变换、无效参数拒绝、列表外部刷新。
- Android：封闭形状像素与指定位置灌色、后台待打开页面持久性，以及既有前台 MCP 编辑/导出版本一致性。
- Node：配对、中继往返、幂等回执、来源限制与部署脚本回归。
- 服务器仍需同步部署同一工具 schema；本次仓库改动不代表目标服务器已经升级。
