# WE MCP 能力与接入准备

统一画布分支；实际工具定义以 `app/src/main/assets/we-mcp-tools.json` 为准。

## 工作区与页面工具

| 工具 | 已实现的范围 |
| --- | --- |
| `list_workspaces` | 列出/按名称搜索工作区，按活动/归档筛选 |
| `create_workspace` | 创建工作区 |
| `rename_workspace` | 核对旧名称后重命名 |
| `manage_workspace` | 置顶/取消置顶、归档/取消归档；回收站操作保留在 App 内 |
| `list_files` | 分页列出指定工作区的 memory/ 与 Skill 文件 |
| `read_file` | 读取允许格式的文本与 SHA-256；包含落盘的对话快照、首页草稿 JSON 和资料文本 |
| `write_file` | 创建/修改文本资料与 Skill；修改已有文件须匹配 SHA-256；保护会话快照和生成页 |
| `read_page` | 读取指定 PDF 页、已保存笔迹向量、页面图像、区域坐标和批改记录 |
| `publish_learning_page` | 发布新的可书写学习页，支持题目、答题留白、文字、绘图区与简单参考图；保留原页 |
| `get_operation_result` | 查询写操作回执，处理重试/超时 |

写操作需要 `operation_id`；文件更新使用哈希版本检查。外部 Agent 负责理解和推理，MCP 执行明确的数据操作。上述接口不执行任意 Shell，也不读取订阅登录凭据。

## 可以马上组合的场景

1. Agent 找到一个工作区，读取对话快照/资料，再发布一份练习纸。
2. 用户在 PDF 上写答案并落盘；Agent 用 `read_page` 读取图像、笔迹及题目区域，批改后交付新页。
3. Agent 整理错题、学习记录或计划为工作区 Markdown/JSON 文件。
4. Agent 读取已保存的绘画 PDF 与笔迹，给出分析/修改建议或发布新的参考页。使用新增画布接口可直接绘制笔画、图形与图层；画布当前仍使用有限 PDF 页坐标。
5. Agent 维护工作区名称、置顶/归档状态和 Skill 文本。

首页草稿 JSON 已可通过文件接口读取，但“直接读取当前首页画面/实时笔尖”不是现有工具。文字/图像模型是否能理解内容由连接的 Agent 决定，MCP 自身不提供模型推理。

## 绘画 MCP（六个新增工具，合计十六个）

| 工具 | 范围 |
| --- | --- |
| `list_canvases` | 分页列出工作区 PDF，包括手写、绘画、导入和生成页 |
| `create_canvas` | 新建独立空白页并通知 App，不替换当前页面 |
| `get_canvas_context` | 读取保存版本、图层、笔画数量；无 path 时读取前台编辑器、选区和视口 |
| `edit_canvas` | 原子批量绘制笔迹、直线、矩形、椭圆、整层填色和局部橡皮；图层新增/修改/选择/排序/复制/删除；笔画移动/缩放/旋转/镜像/复制/删除 |
| `canvas_history` | 同一份持久化撤销/重做历史，App 和 MCP 共用，版本号始终递增 |
| `export_canvas` | 导出含 PDF 底图或透明笔迹的 PNG，返回文件路径、哈希及 MCP 图片预览 |

先读取 `get_canvas_context` / `read_page`，然后携带 `expected_revision` 与稳定 `operation_id` 编辑。笔画索引来自同一版本的 `read_page.ink.strokes`；图层索引按从底到顶排列。坐标使用 PDF 页点，与设备像素、缩放无关。整批失败不会保存部分结果，锁定图层不能绘制或清空。前台仍在落笔或笔迹尚未落盘时，编辑会失败，重新读取后使用新操作编号重试；超时先查询原回执。

当前页打开时直接同步更新画布；页面关闭时写入同一份持久化笔迹，重新进入时恢复。所有原始 PDF 保持不变。历史最多保留二十步并按内容量缩减；导出读取已保存版本，不含未完成笔画。预览为缩略图，PNG 原文件保存在 `memory/exports/`。

这轮没有加入无限画布、逐笔实时流或通用 MCP OAuth。服务端工具目录来自同一 JSON 定义；安装 APK 不能代替中继部署。服务器侧部署说明见 [绘画中继升级](../docs/drawing-mcp-deployment.md)。

## 连接边界

- 正式连接入口统一采用 WordTok 的固定公网 MCP 地址，已移除本机地址与授权头配置入口。
- 电脑/云端 Agent：需要可达的 HTTPS 地址，采用独立中继转发到已配对的 Android。手机执行实际工作区操作，中继转发指令和结果。
- 公网默认地址已设为 https://we.wordrelay.dpdns.org:8444；App 首次配对后复制独立能力地址，以后自动连接。本机 127.0.0.1 地址无法供电脑/云端直连。
- 当前提供配对密钥方案，未实现通用 MCP OAuth。目标客户端必须实测该连接方式。
- Android 进程、网络和后台服务在线时才可处理请求；不承诺离线或被系统强制停止时可用。

部署与协议细节见 [README](README.md)。
